# Changelog

## 0.1.0 — Release candidate

### Implemented

- Rust compiler frontend and typed encrypted IR
- Boolean circuit generation and verification
- TFHE encrypted execution
- Circuit optimization and candidate selection
- Hardware-aware analysis and benchmarking
- Checked lowering APIs and CLI validation
- Cryptographic regression and boundary tests

### Known limitations

- Supported language subset only
- Hardware cost-model accuracy varies by workload
- Experimental calibration corrections are not deployed
- No independent cryptographic security audit

Release date: pending final validation.
